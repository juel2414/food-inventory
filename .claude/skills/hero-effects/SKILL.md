## 이 세션에게 부탁하는 것

이 프로젝트의 첫 화면(히어로)에 아래와 같은 효과를 넣어 주세요.
- 큰 글자 로고가 아래에서 잘려 올라오고, 제목 단어가 흐림→또렷, 나머지가 차례로 떠오름
- "o" 글자 안의 파란 반달이 부드럽게 차오름 (1.75초 시작, 1.4초)
- 반달이 반쯤 찼을 때(2.05초) 빛이 큰 글자를 한 번 휩싸고 사라짐 (은은하게)
- 배경: 천천히 번지는 빛(Animated Gradient · Bloom · Silk 계열) + 가는 격자선과 먼지 점(Hero Minimalism 계열)
- 마우스 시차(카드 > 손그림 > 큰 글자), 시작 버튼이 커서를 살짝 따라옴, 스크롤하면 큰 글자가 떠오르며 옅어짐
- 아래 섹션: 화면에 들어올 때 한 번씩(제목 잘려 올라오기, 취소선 긋기, 숫자 올라가기 등)

## 꼭 지킬 규칙 (원본 프로젝트의 CLAUDE.md 21st 규칙)

1. 21st 컴포넌트를 참고할 때는 **먼저 후보를 보여 주고, 사용자가 고르기 전에는 코드를 고치지 않는다.**
2. React/Tailwind 코드를 **복사하지 않는다.** 모양과 동작만 **순수 JS + CSS**로 다시 만든다.
3. 애니메이션 라이브러리(framer-motion 등)는 쓰지 않고 **CSS 트랜지션/키프레임**으로 대체한다. 불가능하면 먼저 묻는다.
4. 21st의 영어 문구는 그대로 쓰지 않고, **한국어/영어 두 벌**로 새로 쓴다.
5. 이 프로젝트의 클래스 구조·색·글꼴을 따른다. (원본은 랜딩 클래스 `lp-` 접두사, 문구는 `LANDING_TEXT` ko/en)
6. **움직임 줄이기**(prefers-reduced-motion) 설정이면 효과를 넣지 않는다.

## 동작 원리 (짧게)

- 효과는 루트(`.landing`)에 `lp-fx` 클래스가 있을 때만 켜지고, 한 프레임 뒤 `is-in`을 붙이면 CSS 트랜지션이 차례로 실행돼요. (움직임 줄이기면 `lp-fx`를 안 붙임)
- 글자 하나하나는 `lpChars()`가 `<span class="lp-char" style="--i:n">`으로 감싸고, `--i`로 지연 시간을 줘요.
- "o"는 SVG 3조각: 링 2개(`lp-o-ring`) + 파란 반달(`lp-o-arc`, `pathLength="100"`으로 dash 길이를 100으로 맞춰 부드럽게 차오르게).
- 빛은 큰 글자를 **똑같이 하나 더 겹쳐 놓은 복사본**(`.lp-wm-shine`)에 그라데이션 마스크를 씌워 왼쪽→오른쪽으로 한 번 지나가게 해요. `.lp-wm-wrap::after`가 은은한 후광.
- 배경 빛은 블러 처리한 원 4개(`.lp-hero-bloom i`)가 천천히 떠다니는 키프레임.
- 아래 섹션은 `IntersectionObserver`로 화면에 들어오면 `is-seen`을 붙이고, `--ri`(차례 번호)로 지연.

## 다른 프로젝트에 옮길 때

- 큰 글자 단어·SVG 모양·색(`--ink #141414`, `--blue #3B5BA5`, `--light #f2f2ef`)은 그 프로젝트에 맞게 바꾸세요.
- 클래스 접두사 `lp-`는 그 프로젝트 규칙에 맞게 바꿔도 돼요. (바꾸면 CSS·JS 둘 다)
